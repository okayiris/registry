# Licensing

Every entry names its own license in its `skill.json` or `mcp.json`, and that license is the one that
applies to that entry:

- a skill is knowledge, so it is shared under a Creative Commons license (`CC-BY-4.0` by default);
- an MCP server carries code as well, so it names a software license (`MIT`, `Apache-2.0`, ...).

The rules, the formats and the review this repository follows are documented at
https://skills.okayiris.com/docs.md and https://mcp.okayiris.com/docs.md. If an entry is here, its author
has agreed to share it under the license it names, and a person has read it before it was published.
